Orquestração de Agentes

Orquestração é coordenar múltiplos agentes de IA para resolver tarefas complexas — cada um com escopo e ferramentas próprias.

🎯

Orquestrador

Recebe a tarefa principal, decompõe e delega para sub-agentes.

🤖

Sub-agente

Especialista em uma tarefa única. Retorna resultado estruturado.

🔧

Tools

Funções que o agente pode invocar: bash, read, search, API calls.

📋

Context window

Cada agente tem memória limitada — sub-agentes protegem o contexto principal.
