XP — Os 5 Valores Fundamentais

"XP é sobre dar às pessoas o que elas precisam para ter sucesso no trabalho."

— Kent Beck

💬

Communication

Time alinhado é mais rápido que documentação. Conversas frequentes.

🎯

Simplicity

A solução mais simples que funciona agora. Sem YAGNI.

🔄

Feedback

Loops curtos. Testes, CI, cliente on-site. Corrigir rápido.

🦁

Courage

Refatorar, deletar código ruim, dizer que não. Sem medo.

🤝

Respect

Cada contribuição importa. Ninguém é mais importante que o time.
