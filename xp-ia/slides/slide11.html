Criando um Agente — Anatomia + Demo

⬤ LIVE

ANATOMIA DE UM AGENTE

Role

Quem o agente é. Define tom e especialidade. Seja específico.

Goal

O que ele deve entregar. Uma responsabilidade só.

Tools

Funções que pode invocar. Princípio do menor privilégio.

Constraints

O que ele não pode fazer. Evita alucinação e escopo rastejante.

Output

Formato estruturado. JSON ou Markdown — nunca texto livre.

XP aqui: Single Responsibility + testes de contrato no output do agente = TDD para IA.

// Agente de code review — Claude SDK

const agent = await anthropic.messages.create({

  model: "claude-sonnet-4-6",

  system: `

    You are a senior code reviewer.

    Focus ONLY on: security, tests, naming.

    Return JSON: { issues[], score, verdict }

  `,

  tools: [

    { name: "read_file", description: "..." },

    { name: "search_pattern", description: "..." }

  ],

  messages: [{

    role: "user",

    content: `Review: ${diff}`

  }]

})
