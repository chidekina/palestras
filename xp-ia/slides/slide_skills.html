Skills — Comportamentos Injetáveis

Skills são instruções especializadas que modificam o comportamento do agente IA para uma tarefa específica — carregadas sob demanda via /skill-name.

É como um playbook de XP que o dev injeta no agente antes de começar uma tarefa.

1

Dev invoca a skill antes de qualquer ação — ex: /gsd:plan-phase

2

Skill carrega contexto específico: checklist, regras, ferramentas

3

Agente segue o fluxo da skill como um pair seguiria um processo XP

4

Skills rígidas (TDD, debug): siga exato. Flexíveis (patterns): adapte
